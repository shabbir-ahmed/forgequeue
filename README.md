# ForgeQueue

A type-safe job queue engine built with TypeScript.

## Features

- Generic job payloads
- FIFO job processing
- Job state management
- Completion and failure handling
- In-memory storage
- Unit tests

## Tech Stack

- TypeScript
- Node.js
- pnpm
- Vitest

## Setup

Install dependencies:

    pnpm install

Run type checking:

    pnpm typecheck

Run tests:

    pnpm test

## Status

Version 0.1 - Initial in-memory engine.

Distributed workers and persistent storage are planned.
